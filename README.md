# Portfolio · GitHub Pages

Première version du portfolio en français, centrée sur le projet Stiddi.

## Fichiers

- `index.html` : page complète, styles intégrés, adaptée aux écrans mobiles.
- `.nojekyll` : publication des fichiers statiques sans traitement Jekyll.

Aucune installation ni compilation n’est nécessaire.

## Prochaines améliorations

Ajouter les coordonnées professionnelles, le lien App Store et les détails techniques du projet. Remplacer la composition typographique illustrative par de vraies captures si souhaité.

## Publication prévue

1. Créer ou sélectionner le dépôt `madamanastasia/madamanastasia.github.io`.
2. Placer les fichiers de ce dossier à la racine de la branche `main`.
3. Dans GitHub, ouvrir **Settings → Pages** et sélectionner la publication depuis la branche `main`, dossier racine (`/`).
4. Vérifier la réussite du déploiement avant de partager l’adresse prévue : `https://madamanastasia.github.io/`.

Documentation officielle : https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site
